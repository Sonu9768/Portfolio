HOW TO ADD YOUR POSTER DESIGNS:

Method 1: (Easiest)
1. Drop your poster image files in this 'posters' folder.
2. Rename them to numbers, like: 1.jpg, 2.jpg, 3.png, 4.webp, etc.
3. The website will automatically detect and show them!

Method 2: (Keep your file names)
1. Drop your poster files here (e.g. 'my-cool-poster.jpg').
2. Open 'design/script.js' in your code editor.
3. Find the line that says: const customPosters = [];
4. Add your file names in the brackets like this: 
   const customPosters = ['my-cool-poster.jpg', 'another-design.png'];
5. Save the file.

Your posters will show up beautifully on your new /design page!
